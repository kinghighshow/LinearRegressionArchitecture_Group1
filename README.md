# Linear Regression Architecture Workshop

This project implements the Linear Regression Architecture Workshop.

## Current progress
- Part 1: Data sourcing and exploratory data analysis (EDA)

## Python environment

Create and activate the project virtual environment from the repository root:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Use the `.venv` interpreter for Python scripts in VS Code. Select the
`LinearRegressionArchitecture_Group1` kernel for notebooks; it is installed by
the `ipykernel` dependency and uses the same packages as the scripts.
